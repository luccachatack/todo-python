# ToDo em Python

Projeto experimental de pequeno porte para testar ideias, organizar mudanças incrementais e manter um fluxo de desenvolvimento no GitHub.

## Sobre o projeto

A aplicação oferece uma lista de tarefas executada pelo terminal. O escopo é intencionalmente simples, permitindo evoluir funcionalidades em ciclos curtos e manter um histórico claro das decisões do projeto.

## Funcionalidades

- Cadastro de tarefas pelo terminal
- Validação de entradas vazias
- Exibição numerada das tarefas cadastradas

## Como executar

É necessário ter o Python 3 instalado. No diretório do projeto, execute:

```bash
python todo.py
```

Digite as tarefas desejadas e use `sair` para encerrar e exibir a lista.

## Status

Projeto experimental em evolução. Novas funcionalidades podem ser adicionadas conforme os testes e estudos realizados no repositório.
